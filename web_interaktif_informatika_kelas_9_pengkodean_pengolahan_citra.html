Perbandingan Model-Model Warna

RGB
Model Aditif (Layar/Monit)

Pencampuran cahaya warna **Red, Green, Blue**. Ketika ketiga warna bernilai maksimum (255,255,255), maka tercipta warna **Putih**.

Digunakan pada: HP, TV, Laptop, Kamera
CMYK
Model Subtraktif (Percetakan)

Pencampuran pigmen tinta **Cyan, Magenta, Yellow, Key (Black)**. Semakin banyak tinta dicampur, warna akan semakin gelap menuju **Hitam**.

Digunakan pada: Printer, Majalah, Banner
HSL / Gray
Persepsi & Derajat Keabuan

**HSL**: Hue (jenis warna 0-360°), Saturation (kejenuhan), Lightness (kecerahan).
**Grayscale**: Menyimpan kecerahan saja (0=Hitam, 255=Putih).

Digunakan pada: Desain Grafis & Edit Foto

3 & 4. Perbedaan Raster vs Vektor & Aplikasinya

Coba perbesar (zoom) simulasi di bawah untuk melihat perbedaan mendasar piksel dan garis matematis.

GAMBAR RASTER (Bitmap)

Efek Zoom: Terbentuk dari piksels. Saat di-zoom, terlihat kotak-kotak piksel (Pecah / Pixelated).

GAMBAR VEKTOR (SVG / Path)

Efek Zoom: Terbentuk dari garis matematis & kurva. Selalu tajam dan halus di ukuran berapa pun (Anti-Pecah).

Pratinjau Hasil Rendering:

Perhatikan bagaimana penurunan kedalaman bit membuat gradasi warna menjadi bergaris (posterisasi) dan penurunan resolusi membuat gambar kabur/buram.

Resolusi (Resolution)

Jumlah piksel (panjang x lebar). Semakin tinggi resolusi, semakin detail gambar tetapi ukuran file membesar.

Bit Depth (Kedalaman Bit)

Jumlah bit yang digunakan untuk menyimpan warna per piksel. 1-bit = 2 warna, 8-bit = 256 warna, 24-bit = 16.7 juta warna.

Kompresi (Lossy vs Lossless)

Lossy membuang data piksel demi ukuran kecil (JPEG). Lossless mempertahankan detail sempurna tanpa buang data (PNG).

6. Format File Gambar Standar

Mengenal berbagai format file, fitur transparansi, kompresi, serta rekomendasi penggunaannya.

.JPG / .JPEG Kompresi Lossy

Joint Photographic Experts Group

  • Cocok untuk foto berwarna kaya
  • Tidak mendukung transparansi
  • Tidak mendukung animasi
Penggunaan Terbaik: Foto kamera, galeri web.
.PNG Kompresi Lossless

Portable Network Graphics

  • Mendukung Transparansi (Alpha Channel)
  • Kualitas tetap tajam sempurna
  • Ukuran file bisa relatif besar
Penggunaan Terbaik: Logo tanpa background, screenshot, grafik web.
.GIF Maks 256 Warna

Graphics Interchange Format

  • Mendukung Animasi bergerak
  • Mendukung transparansi sederhana
  • Warna sangat terbatas (8-bit)
Penggunaan Terbaik: Meme animasi pendek, stiker percakapan.
.SVG Format Vektor

Scalable Vector Graphics

  • Tidak pernah pecah saat di-zoom
  • Ukuran berkas sangat kecil
  • Tidak cocok untuk foto riil
Penggunaan Terbaik: Ikon web, logo modern, ilustrasi.
.WEBP Format Web Modern

WebP Image Format

  • Kompresi sangat tinggi & ringan
  • Mendukung Transparansi & Animasi
  • Dikembangkan oleh Google
Penggunaan Terbaik: Website modern cepat loading.
.BMP / .TIFF Uncompressed

Bitmap / Tagged Image Format

  • Menyimpan data piksel murni tanpa rugi
  • Ukuran berkas sangat besar
  • Lambat diunduh di internet
Penggunaan Terbaik: Percetakan profesional & arsip foto mentah.
